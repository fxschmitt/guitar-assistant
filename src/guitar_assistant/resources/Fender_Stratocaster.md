# Guitar Spec Sheets - Manufacturer Reference

## Model Profile: Fender Stratocaster

**Document ID:** SPEC-FENDER-STRAT-REV1.0

**1. Overview**
The Stratocaster was introduced by Fender in 1954 as a more contoured, versatile successor to the
Telecaster. It added a synchronized tremolo bridge, a third pickup, and a double-cutaway body
shape, and remains the best-selling electric guitar model of all time.

**2. Technical Specifications**

| Feature              | Specification                                    |
| --------------------- | ------------------------------------------------ |
| **Manufacturer**      | Fender                                           |
| **Body Wood**         | Alder or Ash                                     |
| **Neck Wood**         | Maple, bolt-on                                   |
| **Fingerboard**       | Maple or Rosewood                                |
| **Scale Length**      | 25.5 in (648 mm)                                 |
| **Pickups**           | 3x Single-coil (bridge, middle, neck)            |
| **Bridge**            | Synchronized tremolo (vibrato arm)               |
| **Controls**          | 1x Volume, 2x Tone, 5-way selector switch         |
| **Typical Weight**    | 7.5 - 8.5 lb (3.4 - 3.9 kg)                       |
| **Year Introduced**   | 1954                                             |

**3. Distinguishing Features**
The Stratocaster's synchronized tremolo bridge allows pitch-bend vibrato effects not available on
the Telecaster's fixed bridge. Its double-cutaway, contoured body improves upper-fret access and
playing comfort, and the 5-way switch (versus the Telecaster's 3-way) unlocks two additional
"in-between" pickup combinations prized for their scooped, glassy tone.

**4. Notable Users and Genre Association**
Associated with blues, rock, and funk players (e.g. Jimi Hendrix, Eric Clapton, David Gilmour).
Supports tremolo/vibrato arm as standard equipment.
