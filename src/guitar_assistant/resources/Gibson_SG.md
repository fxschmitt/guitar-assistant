# Guitar Spec Sheets - Manufacturer Reference

## Model Profile: Gibson SG

**Document ID:** SPEC-GIBSON-SG-REV1.0

**1. Overview**
The Gibson SG ("Solid Guitar") was introduced in 1961 as a lighter, slimmer redesign of the Gibson
Les Paul, which it briefly replaced in Gibson's lineup before both continued as separate models.
Its sharp double-cutaway horns and all-mahogany construction give it a tonal and visual profile
distinct from Fender's bolt-on-neck, alder/ash-bodied designs.

**2. Technical Specifications**

| Feature              | Specification                                    |
| --------------------- | ------------------------------------------------ |
| **Manufacturer**      | Gibson                                           |
| **Body Wood**         | Mahogany                                         |
| **Neck Wood**         | Mahogany, set-neck (glued)                       |
| **Fingerboard**       | Rosewood                                         |
| **Scale Length**      | 24.75 in (629 mm)                                |

| **Bridge**            | Fixed tune-o-matic with stopbar tailpiece (or Maestro vibrola) |

| **Typical Weight**    | 6.0 - 7.0 lb (2.7 - 3.2 kg)                       |

**3. Distinguishing Features**
The SG's humbucker pickups produce a thicker, warmer, higher-output tone than the Telecaster's or
Stratocaster's single-coils, with less susceptibility to electrical hum. Its set-neck (glued)
construction, versus the Fender models' bolt-on necks, is often cited for sustain differences, and
its slimmer mahogany body makes it noticeably lighter than a comparable Les Paul.

**4. Notable Users and Genre Association**
Associated with hard rock and heavy blues players (e.g. Angus Young, Tony Iommi, Derek Trucks).
Shorter scale length than either Fender model, contributing to slightly lower string tension at the
same tuning.
