# Guitar Spec Sheets - Manufacturer Reference

## Model Profile: Fender Telecaster

**Document ID:** SPEC-FENDER-TELE-REV1.0

**1. Overview**
The Telecaster is Fender's original solid-body electric guitar, introduced in 1950 (initially as
the Broadcaster/Nocaster before the Telecaster name was adopted in 1951). It established the
bolt-on-neck, single-cutaway solid-body format that the rest of the Fender lineup would build on,
and remains in continuous production today.

**2. Technical Specifications**

| Feature              | Specification                                    |
| --------------------- | ------------------------------------------------ |
| **Manufacturer**      | Fender                                           |
| **Body Wood**         | Ash or Alder                                     |
| **Neck Wood**         | Maple, bolt-on                                   |
| **Fingerboard**       | Maple or Rosewood                                |
| **Scale Length**      | 25.5 in (648 mm)                                 |
| **Pickups**           | 2x Single-coil (bridge + neck)                   |
| **Bridge**            | Fixed, 3- or 6-saddle string-through-body         |
| **Controls**          | 1x Volume, 1x Tone, 3-way selector switch         |
| **Typical Weight**    | 6.5 - 7.5 lb (2.9 - 3.4 kg)                       |
| **Year Introduced**   | 1950 (as the Broadcaster)                        |

**3. Distinguishing Features**
The Telecaster's defining trait is its bridge pickup, mounted on a metal bridge plate that gives it
a brighter, twangier tone than the Stratocaster's. Its fixed (non-tremolo) bridge and simple
control layout make it a favorite for country, blues, and rock rhythm playing where tuning
stability and tonal clarity matter more than pitch-bend effects.

**4. Notable Users and Genre Association**
Associated with country, blues-rock, and punk players (e.g. Keith Richards, Bruce Springsteen).
Does not support a tremolo/vibrato arm in its standard configuration.
